- No Codex, Claude or Copilot CLI or provider API credentials were available. The opt-in provider CLI fixture harnesses were not executed.
- Behavioral evaluation applied actual reviewer prompts through available ChatGPT review agents, using source inspection and focused executable checks. It did not execute the seven-specialist/synthesis/extraction/independent-scoring/triage provider pipeline.
- This is a single qualitative evaluation, not a blinded, repeated, pinned-model accuracy benchmark. Some evaluators had prior fixture metadata context from the preceding audit; no current oracle or other evaluator result was supplied to them.
- Agent-assigned confidence values are included as review output, not calibrated probabilities or scores from the original independent confidence stage.
- Go, TypeScript, React/browser, Vitest and full external service environments were not installed. Validation descriptions distinguish source/documentation checks from executed code.
- Targeted expectation satisfied means the intended positive defect or negative guard was assessed correctly; it does not claim exhaustive correctness or zero additional findings.
